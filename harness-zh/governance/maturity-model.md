# Harness 成熟度模型

| 阶段 | 交付物 | 达标条件 |
|---|---|---|
| F0 基础 | 项目画像、文档优先级、安全红线 | 团队可识别命令、负责人和审批边界 |
| F1 可重复 | 统一入口、质量门禁、需求/设计/测试模板 | 本地检查可重复，变更有证据记录 |
| F2 可指导 | 模块化规则、技术栈适配、Setup/Debug/Review Skills | 常见变更与故障均有明确工作流 |
| F3 可强制 | Hook、秘密扫描、SAST、覆盖率、CI 分支保护 | 必需门禁不能依赖人工口头放行 |
| F4 可演进 | 指标、例外复盘、规则有效性审查、组织分发 | 重复问题持续回灌并度量改进效果 |

升级前必须验证前一阶段已被实际使用；不得以新增文档替代真实门禁或证据。
