# 文档优先级

当指令发生冲突时，使用最高优先级且适用的来源，并记录冲突处理结论。

1. 法律、法规、合同义务和平台政策。
2. 处于活跃事件时，事件总指挥或安全负责人指令。
3. 仓库安全策略与用户的明确授权。
4. 本 Harness 的安全和数据策略。
5. 已批准的架构、需求和质量门禁契约。
6. 团队工作流和编码规范。
7. 实现说明和便捷性指引。

## 权威记录

- 产品意图：需求记录。
- 普通缺陷生命周期与历史：Bug 台账。
- 跨工作项的交付状态：项目进度。
- 安全、数据和重大运行响应：事件记录。
- 技术权衡：ADR。
- 重大行为或架构：设计记录。
- 已知风险或例外：风险评估和已批准例外。
- 验证：测试计划和实际命令输出。
- 运行发布：发布记录。

任何低优先级文档都不能授权生产访问、凭证使用、安全绕过、破坏性操作或第三方副作用。
