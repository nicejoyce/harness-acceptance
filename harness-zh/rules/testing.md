# 测试规则

- 单元测试验证确定性业务行为，覆盖成功、边界和失败路径，不访问网络或生产依赖，遵循 `TEST-001`、`TEST-002`、`TEST-007`。
- 集成测试使用团队拥有、隔离和可清理的真实组件，禁止触发第三方真实业务，遵循 `TEST-003`、`TEST-009`。
- E2E 至少覆盖关键用户旅程，并同时验证用户可见结果和后端状态，遵循 `TEST-004`。
- 变更行覆盖率不低于 80%，认证、授权、支付、删除和安全模块不低于 90%，总体覆盖率不得下降，遵循 `TEST-005`、`TEST-006`。
- 测试失败、跳过、未配置或无法运行时阻断合并，除非有有效例外，遵循 `TEST-008`。
