# 安全与 Agent 行为边界

## 默认权限模型

默认允许：本地只读检查、静态分析，以及使用隔离本地测试数据且没有外部副作用的测试。

执行前必须审批：超出批准白名单的网络探测；生产或预发访问；凭证使用；CI、部署、认证、授权、数据库 Schema 或公共契约变更；处理个人或客户数据；安装运行时依赖；删除、覆盖、重置、迁移等破坏性操作。

绝对禁止：泄露凭证或私钥；绕过认证；批量创建账号；规避身份或设备识别；规避限流、反滥用控制或平台条款；未授权流量拦截；隐蔽数据外传；未经批准的生产数据库变更。

## Agent 要求

- 执行特权操作前，说明命令、目标、影响及审批要求。
- 最小化数据收集，并在日志和报告中脱敏 Token、密码、个人数据和秘密信息。
- 权限不明确、出现意外数据暴露或安全检查失败时立即停止。
- 外部 HTTP 状态码只能证明可达性，不能证明有权自动化该服务流程。
- 保留用户已有修改；没有明确授权时不得执行破坏性版本控制命令。

## 事件触发

发现疑似泄露、未授权访问或策略违规时，停止工作、保全证据、由指定负责人轮换暴露秘密，并使用 `templates/incident-record.md` 记录。
