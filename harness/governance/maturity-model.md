# Harness Maturity Model

| Stage | Deliverables | Evidence |
|---|---|---|
| F0 Foundation | Profile, document hierarchy, redlines | Commands, owners, approvals are known |
| F1 Repeatable | Standard entrypoints, gates, records | Local checks and change evidence repeat |
| F2 Guided | Module rules, stack adaptation, Skills | Common work and failures have workflows |
| F3 Enforced | Hooks, scans, coverage, CI protection | Required gates cannot rely on verbal approval |
| F4 Evolving | Metrics, exception review, organization distribution | Repeat issues become measured improvements |

Do not claim a stage from documents alone; demonstrate actual use of the prior stage.
